## 第一步：生意本质 — 段永平"对的生意"

**一句话定义：** Amazon 是三门截然不同的生意穿着同一件外衣——电商平台（低利润规模游戏）、AWS 云基础设施（高利润 SaaS 现金奶牛）、广告网络（高利润媒体生意）。

### 收入结构（FY2025 年化 + Q1 2026）

| 业务 | Q1 2026 收入 | 年化估算 | 毛利特征 |
|------|------------|---------|---------|
| AWS | $37.6B | ~$150B | 运营利润率 ~38%，现金奶牛 |
| 广告 | $17.2B | ~$69B | 运营利润率 ~60%+，纯利润 |
| 线上商店 | $64.3B | ~$257B | 低利润，规模效应 |
| 第三方卖家 | $41.6B | ~$166B | 平台抽成，高利润 |
| 订阅（Prime）| $13.4B | ~$54B | 稳定复购，锁定用户 |

**关键洞察：** AWS + 广告占营收约 30%，但贡献了公司 **80%+ 的利润**。电商是流量漏斗，AWS 和广告才是钱袋子。

### 5 年盈利趋势（单位：十亿美元）

| 财年 | 营收 | 净利润 | 毛利率 | 经营利润率 | FCF |
|------|------|--------|--------|-----------|-----|
| FY2021 | 469.8 | 33.4 | 42% | 5.3% | -14.7 |
| FY2022 | 514.0 | -2.7 | 44% | 2.4% | -16.9 |
| FY2023 | 574.8 | 30.4 | 47% | 6.4% | 32.2 |
| FY2024 | 638.0 | 59.2 | 49% | 10.8% | 32.9 |
| **FY2025** | **716.9** | **77.7** | **50%** | **11.2%** | **7.7** ⚠️ |

毛利率从 42% 升至 50%，是 AWS/广告占比上升的直接体现——这是结构性改善，不是周期性好转。

**段永平式追问：** 这门生意好在哪？  
> 三门生意里，AWS 是"铺了基础设施就能源源不断收钱"的生意，广告是"卖家想触达买家别无选择"的生意，这两门都极好。电商是苦生意，但它养活了前两门的用户获取成本。整体是"用苦生意养出了两个印钞机"。

## 第二步：护城河 — 巴菲特"经济护城河"

| 护城河类型 | 强度 | 评估 |
|-----------|------|------|
| 规模效应（物流/AWS）| ★★★★★ | 全球物流网络 + AWS 数据中心规模无人能比 |
| 转换成本（AWS）| ★★★★★ | 企业迁移 AWS 的成本极高，数据/工具深度绑定 |
| 网络效应（电商平台）| ★★★★ | 卖家越多买家越多，买家越多卖家越多 |
| 品牌/Prime 忠诚度 | ★★★★ | Prime 2亿+会员，年费续订率 ~93% |
| 技术/专利壁垒 | ★★★ | AWS 技术领先但 Azure/GCP 正在快速追赶 |

**护城河趋势：** AWS 护城河**稳固但相对收窄**（Azure 增速 39% vs AWS 24%）。电商护城河持续加宽（物流网络继续渗透）。广告护城河快速加宽（购买意图数据是稀缺资源）。

**巴菲特式追问：** 10年后护城河还在吗？  
> AWS 护城河大概率存在但可能变窄——微软凭借 OpenAI 深度绑定的企业软件生态正在构建差异化。广告护城河可能是最被低估的——Amazon 的购买数据比 Google 更精准（买过 vs 搜过）。

## 第三步：逆向思考 — 芒格"反过来想"

### 失败路径清单

| 失败路径 | 概率 | 冲击程度 | 说明 |
|---------|------|---------|------|
| **FCF 长期受压，资本支出不带来回报** | 中（35%）| 极高 | $200B Capex 若 AI 投资回报延迟，2027 FCF 仍低迷 |
| **FTC 反垄断胜诉，被迫剥离 AWS** | 低（10%）| 毁灭性 | 2027 年初开庭，若 AWS 剥离则估值框架彻底瓦解 |
| **Azure/GCP 蚕食 AWS 份额** | 中（40%）| 高 | Azure +39% vs AWS +24%，差距在扩大 |
| **消费者支出下滑打击电商** | 中（30%）| 中 | 经济衰退时电商先受压，Prime 降价压力上升 |
| **估值收缩（业务完好但PE压缩）**| 高（50%）| 中 | 33x PE → 20x PE = 股价腰斩，即使业务正常 |
| **AI 资本支出 ROI 延迟兑现** | 高（55%）| 高 | $200B Capex 的回报 2027-28 年才能验证 |

**最大空方论据（核心）：**  
Q1 2026 资本支出 $44.2B（同比 +77%），而 TTM FCF 骤降至约 $1.2-7.7B。市场在定价"未来 AWS 超强回报"，但如果回报延迟两年，当前 33x PE 完全无法支撑。

**芒格式追问：** 我最可能在哪里犯错？  
> 被 AWS 高利润率迷惑，忽视了 Azure 增速更快这一事实，以及 FTC 诉讼是个真实的二元风险——赢了没事，输了估值框架崩塌。

## 第四步：管理层评估 — 段永平"对的人"

| 时间 | 决策 | 结果 | 评分 |
|------|------|------|------|
| 2006 | 把内部 IT 基础设施商业化→AWS | 创造了万亿云计算市场 | ★★★★★ |
| 2005 | 推出 Prime 会员 | 锁定 2 亿+消费者，年费复购机器 | ★★★★★ |
| 2014 | 收购 Twitch、进军广告 | 广告现成为第二大利润中心 | ★★★★ |
| 2017 | 以 $137B 收购 Whole Foods | 协同效应有限，溢价偏高 | ★★★ |
| 2021 | Andy Jassy 接任 CEO | 过渡顺滑，AWS 出身，战略延续 | ★★★★ |

**Andy Jassy 评估：** AWS 创始人，深度技术背景，资本配置纪律性强（2022 年大幅裁员 27,000 人，快速恢复盈利）。但知名度和长远判断力与贝索斯仍有差距。

**段永平式追问：** 如果 CEO 退休，竞争力还在吗？  
> AWS 和广告的护城河是系统性的，不依赖某一个人——比 NVDA 的 Jensen 依赖度低得多。Jassy 退休后短期波动但长期影响有限。

## 第五步：行业趋势 — 李录"文明演进框架"

**判断：** Amazon 处于两个文明级趋势的交叉点：
1. **云计算基础设施化**（已完成大半，AWS 是标准基础设施）
2. **AI 计算爆发**（正在发生，$200B Capex 就是押注）

**TAM 分析：**

| 市场 | 现状 | 2030E |
|------|------|-------|
| 全球云计算 | $600B | $1.2T+ |
| 电商（全球） | $6T | $8T+ |
| 数字广告 | $700B | $1T+ |

Amazon 在三个市场都有重要地位，但没有一个是绝对垄断。

**李录式追问：** 20 年后是"标准石油"还是"3Com"？  
> AWS 更接近"这个时代的标准电力公司"——企业用 AWS 就像工厂用电，不会轻易换。但电商业务长期面临更多竞争（Temu、Shein、TikTok Shop），不是时代级垄断。

## 四位大师模拟点评

> **巴菲特：** "AWS 是这个时代最好的商业模式之一——客户用了就很难走，还在帮你建护城河。但 $237 的价格已经很好地反映了这一点，我需要等一个明显的错误定价。$200 我会认真考虑。"
